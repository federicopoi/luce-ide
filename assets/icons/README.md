# Interface icons

Selected regular-weight SVGs from @phosphor-icons/core 2.1.1.
Source: https://github.com/phosphor-icons/core
Distribution: https://www.npmjs.com/package/@phosphor-icons/core/v/2.1.1
MIT license retained in LICENSE. Original geometry is unchanged.

Desktop and mobile share src/shared/icons.js; icons are bundled locally,
with no icon CDN or font dependency. Luce and provider brand marks are separate.

`cloudflare.svg` is an original Luce cloud-interface illustration, licensed under
Luce’s MIT license. It is not an official Cloudflare brand mark.
